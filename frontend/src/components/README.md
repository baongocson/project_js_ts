# Components hiện có

Thư mục này có trước refactor và hiện chỉ có placeholder, không chứa component triển khai. Giữ lại để tránh tự suy diễn yêu cầu xóa toàn bộ src/components.

Component mới thuộc một feature đặt ở features/<name>/components; primitive dùng chung đặt ở shared/ui. Hiện không có code cần di chuyển hoặc export ở đây. Có thể bỏ placeholder này trong lần dọn cấu trúc sau nếu nhóm xác nhận không dùng.
